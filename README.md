# AI Color Detection

A real-time color detection project built using Python and OpenCV.

## Features
- Real-time webcam video capture
- Dominant color detection using K-means clustering
- Image processing with OpenCV and NumPy

## Technologies Used
- Python
- OpenCV
- NumPy

## Installation

Install the required dependencies:

```bash
pip install -r requirement.txt
```

## Run the Project

```bash
python main.py
```

Allow webcam access when prompted.

## Project Goal
To identify dominant colors in a live webcam feed using computer vision.
